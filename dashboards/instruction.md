# Инструкция выбора дашборда

По вопросу пользователя выбери **один** файл `.mrt` из списка.

## demo.mrt
Общий демо-дашборд, тестовые данные, «покажи пример», карта/таблицы без узкой темы.

## Когда появится revenue.mrt
Выручка, платежи, доходы, динамика по месяцам/годам, единицы тыс./млн.
